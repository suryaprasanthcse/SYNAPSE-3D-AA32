# SYNAPSE-3D: UAV Disaster-Assessment Agent (Hack Matrix AA-32)

A neuro-symbolic drone agent that runs on an Android phone in AR. A language model (Gemini) reads a free-text
earthquake field report and builds a **zone map**: collapses, unstable buildings, a helicopter landing zone and
radio relays. Deterministic C# on the device then checks that map against safety and communications rules,
plans a lawnmower survey route over it, flies a drone along the route in AR, and reports each zone the moment it
has been imaged.

- **Problem statement:** Hack Matrix, Agentic AI track, AA-32: Post-Earthquake Damage-Assessment Drone Agent
- **Engine:** Unity 6000.6.0f1, URP, AR Foundation (Android / ARCore, IL2CPP)
- **Scene:** `Assets/Scenes/AA32_DroneAgent.unity`

## 2. Built during Hack Matrix (24–25 Sep)

Everything below was written during the event: commits `a77a7ec` (24 Sep, 14:33) to the release commit.

**The agent (`Assets/_HackMatrix_Agent`)**
- **AA-32 vocabulary and prompt:** LaunchPad, HazardZone, ShoringSite, RescueLZ and RelayNode, with the model
  instructed to produce a structural zone map, never waypoints.
- **ReAct tool-calling loop** (`PlannerAgentLoop.cs`, `LlmChatClient.cs`): Gemini calls
  `calculate_flight_path(zone_map)`. The tool runs the verifier and planner on the device and returns VERIFIED
  with the route, or REJECTED with every violation and its fix. The model repairs its map and calls again, up to
  4 calls. Gemini 3 thought signatures are echoed back verbatim. If the endpoint refuses tools, the agent falls
  back to the Round 1 JSON loop.
- **On-board coverage planner** (`FlightPlanner.cs`): a deterministic boustrophedon (lawnmower) sweep with lanes
  one sensor-swath apart. It climbs over structures instead of detouring. Coverage is defined once and shared
  with the verifier.
- **Symbolic verifier** (`PlanVerifier.cs`). Zone-map rules: bounds, overlap, landing-zone buffer from collapses,
  required zones. Path rules: altitude clearance, bounds, coverage.
- **Radio-relay connectivity:** every RescueLZ must chain back to the LaunchPad through RelayNodes, with no hop
  over 0.50 m (AR scale). A breadth-first search gives exact hop counts, and landing zones never relay. An
  isolated landing zone is rejected with the exact relay positions that would connect it.
- **Incremental dispatch and measured latency:** each zone is reported the moment it is fully imaged. The HUD
  shows wall-clock time to first dispatch against time to full survey.
- **AA-32 offline zone map:** the map the drone flies when the uplink is lost. It passes the same verifier.
- **Simulated damage classifier:** a threshold rule benchmarked on 20 synthetic cases (15/20). The HUD labels it
  as simulated; it is **not** a vision model.
- **HUD:** agent state (TOOL CALLING), per-round tool verdicts, relay network status (VERIFIED, N HOPS, or
  ISOLATED), latency and frame timing.

**The AR scene and assets**
- **Composite zone prefabs and URP materials**, generated by Editor scripts: `SetupAA32Assets.cs`
  (Hack Matrix > AA-32 menu).
- **External-model pipeline** (`SetupAA32External.cs`, `GltfMeshImporter.cs`): re-materials third-party models
  with URP Lit, strips colliders, fits them to the verifier's zone boxes, and converts glTF to Unity meshes.
  Buildings keep their own textures, and zones are marked with glowing base pads.
- **Lighting for Lit materials:** the base engine's dark-AR lighting is switched off in this scene.

## 3. Running it

1. Open the project in Unity 6000.6.0f1 with the Android module installed, then open
   `Assets/Scenes/AA32_DroneAgent.unity`.
2. **API key:** the key field in `HackMatrix_Agent > AgenticLLM_Bridge` is intentionally empty. Paste a Gemini
   API key there for the live path. Without one, the agent flies the on-board zone map, and the HUD says
   "UPLINK LOST".
3. Press Play (XR Simulation) or build for Android.
4. Self-tests: **Hack Matrix > AA-32 > Self-Test Offline Zone Map** and **Self-Test Relay Network**.
